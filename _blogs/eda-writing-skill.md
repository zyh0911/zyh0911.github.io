**[EDA-Writing-Skills](https://github.com/zyh0911/EDA-Writing-Skills)** is a Claude Code skill for writing papers aimed at top EDA venues such as DAC, ICCAD, DATE, ASP-DAC, and TCAD. It helps rewrite drafts so reviewers find them clear. It covers:

- **Section guides** for the Abstract, Introduction, Related Work, Method, Experiments, and Conclusion.
- **Paragraph polishing**: one message per paragraph, logical flow between sentences, and a reverse-outline check.
- **Claim–evidence alignment**: every major claim must be backed by experiments.
- **A pre-submission self-review** from a skeptical reviewer's point of view.

Installation and usage are in the [repo](https://github.com/zyh0911/EDA-Writing-Skills). It builds on [Master-cai/Research-Paper-Writing-Skills](https://github.com/Master-cai/Research-Paper-Writing-Skills), adapted with my own experience submitting to EDA venues.
